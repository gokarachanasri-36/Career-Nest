# CAREER NEST

### Find genuine opportunities. Build a better-matched resume. Apply with confidence.

## About

CAREER NEST is a career platform designed for:

- College Students
- Freshers
- Entry-Level Job Seekers

## Problem

- Difficult to find genuine jobs and internships.
- Opportunities are scattered across different platforms.
- Some listings may be fake, outdated, or closed.
- Students often use the same resume for different jobs.
- Resumes may not match the specific Job Description (JD).

## Solution

CAREER NEST provides:

- Verified/Genuine job opportunities.
- Internship opportunities.
- Live and Closed opportunity sections.
- AI-powered Resume Analyzer.
- ATS-style resume score.
- Job-resume skill matching.
- Missing skill identification.
- Resume improvement suggestions.
- AI career guidance chatbot.

## Resume Analyzer

**Input:**
- Existing Resume
- Job Description

**Output:**
- ATS Score
- Resume Match %
- Matching Skills
- Missing Skills
- Improvement Recommendations
- Tailored Resume

**Important:**  
The system must not add fake skills, projects, certifications, education, achievements, or experience. It only improves the user's existing information.
